# Notebook status

These files preserve the completed IBM course sequence. They are archival
coursework, not the canonical reproducibility gate. The API and web-scraping
notebooks depend on external services and can become stale; the web-scraping
notebook is intentionally noncanonical. Run `spacex_analysis.py` against the
checked-in fixture for a network-independent smoke test.

All saved execution outputs were removed on this remediation branch so a stale
exception or hidden state is not presented as a result. Re-run individual
notebooks only after retrieving the source files listed in
`data/SOURCE_MANIFEST.json`.
